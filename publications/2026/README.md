## Included Publication

### Shinsō Ondo Pamphlet

- Filename: `shinso-ondo-pamphlet-20260726.pdf`
- Title: Shinsō Ondo Pamphlet
- Work: *Shinsō Ondo – Shinsō Yoitoko Sanpomichi*
- Release date: July 26, 2026
- Issued by: Sumiyoi Machizukuri Shinsō-kai
- Pamphlet production: Hiroshi Komatsuzaki
- Format: PDF

The pamphlet contains:

- a greeting concerning the production of Shinsō Ondo
- lyrics
- credits for lyrics, music, arrangement, choreography, performance, and vocals
- terms of use
- information about the people involved in the production

---

## File Format

The published PDF has the following characteristics:

- fonts embedded as subsets
- Unicode information retained
- searchable text
- extractable text
- stable visual presentation even when the same fonts are not installed on the viewing device

Because it preserves both visual fidelity and machine readability, the searchable, non-outlined PDF is designated as the official public edition.
